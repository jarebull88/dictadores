# Ideas: frases y hechos reales

Cuaderno de Jorge para ir apuntando frases y hechos reales que pueden servir para el juego. Aquí solo se recogen; cuando se decida dónde usar una, se apunta en «Dónde» y se pasa a `src/datos.js`.

Recordatorio de las reglas: dentro de las cartas no se nombra ningún país real (solo en el `archivo` histórico, marcado «datos pendientes de verificar»), y quien habla con el dictador son sus ministros, el mando militar y los embajadores.
